    Agents

    Specialists Fox can hand work to. Their actions go through the same permission prompts, and each prompt names the agent asking.

    Permissions

    Safe tools run without asking. Normal tools ask, and you can remember the answer. Critical tools ask every time.

    RuleToolTarget

    Turning a tool off hides it from Fox and every agent. The kill switch and plugins are on the Control page.

    Control

    The switches that decide whether Fox may act at all, the tools it can load, and how to wipe what it has stored.

    Kill switch

    Fox is running normally.

    When on, every tool is blocked at once and anything running stops. Chat still works; Fox just can't do anything on your computer until you turn it back off.

    Plugins

    Each plugin is one Python file that adds tools. New tools are on right away, still behind the usual permission prompts, and you can turn any of them off under Permissions. Plugin code runs with the same access as Fox itself, so only add code you trust.

    FileStatusTools it adds

    Reset

    Permanently delete stored data. Pick what to clear, then Reset. This can't be undone.

    Memory

    What Fox has saved. Saved facts are added to every conversation.

    Reminders

    Reminders fire only while Fox is open. Overdue ones appear at the next start.
